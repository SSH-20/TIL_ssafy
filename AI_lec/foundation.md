# 파운데이션 모델
## 1-1. 파인데이션 모델이란?
- 대규모 데이터로 사전학습한 후, 다양한 문제/작업에 범용적으로 빠르게 적응 활용 할 수 있는 기반 AI 모델
  
기존 AI모델 VS 파운데이션 모델
- 기존 딥러닝 개발 패러다임 : 아기와 같이 언어, 시각, 청각, 촉가 등 기본적인 것들부터 배워 나감
- 파운데이션 모델 패러다임 : 거대 모델(커다란 뇌) + 대규모 데이터 학습 (많은 지식과 경험) 기반
  
파운데이션 모델 특징
1. 대규모 사전학습 : 트랜스포머 + 대규모 언어 데이터 학습
    - 테스크에 상관없이 비슷한 패턴들이 활용됨
    - 주로 비지도 학습으로 훈려된 모델들"도" 많이 등장
        * 의미하는 바 : 쉬운 데이터 수집 + 대규모 + 사전학습
    
2. 적응성 : 높은 미세조정 성능 (높은 태스크 적응 성능)
    - 하나의 믿고 쓸 수 있는 모델 &rarr; 다양한 목적에 적용

3. 범용성 : 다양한 작업, 한정되지 않는 출력 지원
    - 예시 : 물체 판별

파운데이션 모델에 의한 AI 모델 개발의 변화
- 과거에는 매번 모델을 태스크 별로 새로 학습했지만, 이제는 잘 학습된 모델들을 얼마나 잘 활용하느냐가 핵심
- 파운데이션 모델 하나 확보를 위해서는 대규모 리소스(데이터, 계산, 전력) 필요 (일부 기관만 가능)

- 적응 활용 (Down-stream task adaptation)
    - 활용 되는 기법들 : 프롬프트 {엔지니어링, 튜닝}, 전이학습, 적응(Adaptation)학습, 파인튜닝

## AGI를 향해서
이미지 학습에 언어 모델을 합쳐볼까?
-> 사고능력과 언어 능력 만으로는 세계를 이해하기 충분하지 않음
  
LLM에 눈을 달아보자 (시각언어모델)
- 예시 : GPT-4 
    - 자연어 입력에 국한된 기존의 거대 언어모델에서 더 나아가 이미지, 문서, 음성 등 멀티모달 데이터를 처리할 수 있는 모델

- 예시 : Computer use, Claude
    - AI agent가 스스로 수 많은 컴퓨터 프로그램을 활용하여 태스크 해결
    - AI agent와 기존 응용 프로그램을 인터페이스하기 위한 표준이 없음
    - 호환성 높은 손쉬운 인터페이스를 하기 위해 이미지 캡쳐 방식이 선호
  
눈으로 어떤 것을 쓸까? CLIP(2021) by Open AI  

CLIP : Contrastive Language-Image Pre-training, by OpenAI
- AI가 언어와 시각을 통합해서 이해하는 방식을 보여준 패러다임 전환 제시
- 파운데이션 모델로서의 특징
    - 입력 : 학습하지 않은 새로운 도메인의 입력 데이터에 대해서도 좋은 성능을 발휘
    - 출력 : 자연어를 이용해 한번도 본 적 없는 카테고리도 텍스트 설명만으로 출력 정의 가능
  
대조 학습 기반 (Contrastive Pre-training)의 언어-이미지 사전 학습
- 인터넷 데이터를 통한 지도 학습을 통해 자연어 기반 시각 학습
- 다양한 이미지-자연어 쌍으로 학습
    - 인터넷에서 수집된 4억개의 이미지-텍스트 쌍

- 다양한 이미지-자연어 쌍으로 학습
    - 텍스트 인코더 : Transformer
    - 이미지 인코더 : ViT 또는 ResNet

CLIP에서는 Encoder Only 구조 사용
  
Remind
- 토큰이라는 단위의 입력
- 입력된 토큰 간의 관계성을 집중하는 Attention 메커니즈믕로 구성
- L 길이의 입력 토큰은 D-차원 특징 벡터(임베딩)의 배열 형태로 입력 (L x D)
- 자연어 데이터 : Sub-word 단위의 임베딩

## 멀티모달 정합 응용
멀티모달 정합 (Multi-modal Alignment)
- 서로 다른 두 가지 이상의 모달리티(예 : 이미지와 텍스트) 간의 공통된 임베딩 벡터 공간을 구성하는 것
- 서로 다른 모달리티 임베딩 간 유사도(연관성) 비교 가능
- 대표적인 모델 : CLIP, ImageBind
  
ImageBIND - One Embedding Space To Bind Them All
- 이미지, 비디오, 텍스트, 오디오, 뎁스, 열화상, IMU 모달리티 공간을 공유하도록 학습

## 3-2 LLaVA
Vision과 language 모델을 결합한 모델(VLM)로, 텍스트와 이미지를 동시에 이해
- 주요 특징
    - 이미지 인식과 텍스트 생성을 결합하여, 이미지 설명 생성 또는 시각적 질문 응답 작업에서 뛰어난 성능
    - 이미지, 명령, 답변이 주어진 데이터셋을 구축하여 instruction tuning으로 학습
- 응용 사례
    - 이미지 기반 질문 응답, 이미지 설명 생성, 시각정 정보 기반 대화 등

    * Projection W 가 이미지를 텍스트로 번역해준다

LLaVA 모델 특징
- 효율적인 메모리 사용 : 적은 자원으로 큰 모델 효과적으로 학습
- 다중 모달 학습 : 텍스트오 시각 데이터를 결합하여 응답을 생성
- Fine-tuning : 특정 작업에 맞춰 모델을 미세조정하여 사용

Step 1 : 사전 학습
- 표현 공유
    - 이미지 텍스트 표현을 변환하는 선형 레이어를 학습하여 텍스트와 이미지를 공통된 토큰 표현으로 처리
    - 전체 모델을 다시 훈련하지 않으므로 자원과 시간 절감
- 효율적인 학습
    - 적은 파라미터만 학습

Step 2 : Fine-tuning
- 표현 공유
    - 특정 작업에 맞춰 선형 레이어와 언어모델 등 필요한 부분만 미세조정으로 강화
- 효율적인 학습
    - 저비용 학습 기법을 통해 메모리 사용량 절감

LLaVA 학습 데이터 (합성 데이터)
- ChatGPT를 활용하여 시각 설명 데이터 생성
    - 기존 coco 데이터셋 : 이미지와 대응하는 이미지 설명, 물체좌표를 라벨 데이터로 제공

- 생성 모델의 응용
    - 실제 데이터와 유사한 이미지 생성
    - 학습 데이터 생성 / 데이터 증강
    - 이미지 화질 개선
    - 이미지 편집, 스타일 변경

- 생성 모델링
    - 데이터셋 : 미지의 데이터 분포로부터의 샘플들
    - 생성모델 : 데이터셋으로부터 데이터 분포를 알아내는 과정
    - 의미 : 미지의 데이터 분포를 알 수 있다면 새로운 데이터를 샘플링(생성) 할 수 있다.
    - 미지의 데이터 분포를 안다는 것은 실제 데이터 x를 생성하는 과정을 정확하게 안다는 것
    - but, 미지의 데이터 분포는 어떤 형태인지는 (우리는) 모름 (신만 앎)
    - 생성모델링의 목표 : 실제 분포를 모르니 유사모델로 근사

- 생성 모델링 문제
    - 모르는 것(구하는 것) : 미지으 데이터 분포
    - 알고 있는 것 : 실제 데이터 셋
    - 실제 생성모델 학습 : 주어진 x로부터 유사모델을 학습

- 생성 모델 설계
    - 설계의 정교함에 따라, 실제 데이터 분포에 가까워 짐  
    -> 생성 품질 향상
    - P_model(x)의 모델 구조는? 학습 방법은?

- 생성 모델 기초
    - Denoising Diffusion Probabilistic Models
        - 최근 성공사례를 보여준 대표적 영상 생성 모델
        - 메커니즘 : 노이즈로부터 점진적으로 노이즈를 제거하며 이미지 구체화 하는 생성 방식
        - 학습법 : 합성 노이즈를 입히고 그 노이즈를 예측하는 문제를 반복 학습하게 유도
        - 단점 : 느림

    - Latent Diffusion Model (LDM)
        - Stable Diffusion에서 소개됨
        - 고차원 픽셀 단위 대신, 저차원 latent 임베딩(=압축된 특징 정보)으로 변환한 후 diffusion 연산을 수행하는 기법
        - 연산 효율을 높임과 동시에 이미지 생성 품질 또한 향상시킴.

    - Latent Diffusion Model 구조
        1) 텍스트 특징 생성(text representation generation)
            - 텍스트 입력을 함축하는 임베딩 값을 얻는 과정
        2) 이미지 특징 개선
            - 텍스트 특징을 바탕으로 생성된 이미지를 점차 개선하여 고품질 이미지를 생성하는 과정

## 1-1. 파운데이션 모델 + Fine-tuning
파운데이션 모델과 미세조정이 필요한 이유
- 방대한 데이터로 학습된 초대형 딥러닝 모델, 다양한 작업이나 범용적인 문제에 바로 적용 가능
- 최근에는 텍스트 뿐만 아니라 이미지, 오디오, 비디오 등의 당야한 입력 데이터를 처리할 수 있는 멀티모달로 확장
- 하지만 최신 정보나 특정한 작업/도메인에 최적화 되어 있지 않아, 즉시 활용이 어려운 경우가 반드시 있음

미세조정(Fine-tuning) : 추가 학습을 통해 이미 학습된 모델을 조금만 튜닝하는 것
- 미세 조정을 통해 특정 작업에 특화된 모델을 개발할 수 있다.
- 파운데이션 모델 + Fine-tuning = 실용적인 개인화 파운데이션 모델
    - 적은 데이터로 학습 가능
    - 학습 리소스 절약 가능
    - 특정 작업에 대한 우수한 성능

## 1-1. AI 리터러시 ++ (강사 생각)
차별화된 AI 종합 활용 능력
- AI의 작동 원리를 이해하고, AI가 생성한 정보를 비판적으로 분석하며, AI를 도구로서 효과적으로 활요할 수 있는 역량 + AI를 내 입맛대로 변경해서 사용할 수 있는 능력

## 1-2. Fine-tuning이란?
- 사전 학습된 모델에 프롬프팅을 통한 작업을 했을 때보다 더 좋은 퀄리티의 결과물 생성
- 프롬프트에 넣는 예제보다 훨씬 더 많은 예제를 통한 학습 가능
- 프롬프트의 길이가 줄어들면서 토큰 개수 절약
- 응답하는 데에 걸리는 시간을 단축

## 1-3. 하이퍼파라미터 - Learning Rate
손실함수가 큰 값일 때 미세하게 조정하기 어려우므로 뉴럴넷 모델에 작은 비율로 반영함  
  
Learning rate : 반영할 비율  
  
적절한 learning rate 값
    - 모델과 데이터마다 달라 실험을 통해 구함
    - 예시 : 0.005배, 0.0003배
  
너무 낮은 learning rate 값
- local minimum에 빠져서 global minimum에 도달할 가능성이 낮아짐

## 1-4. Parameter-Efficient Fine-Tuning (PEFT)
AI 모델의 크기
- 하드웨어의 발전, 대규모 데이터의 축적 그리고 AI모델의 발전에 따라 학습 비용과 모델 용량이 기하급수적으로 증가중임.

효율적인 모델 학습
- 오픈소스로 공개된 고성능 파운데이션 ㅗㅁ델을 출발점으로 미세조정하는 접근이 일반화되었으나, 여전히 높은 비용
- 효율적인 미세조정 방법
    - 프롬프트 튜닝
    - adaptor 모듈 추가 학습.

프롬프트 디자인
- 언어모델에서 주로 활용, 모델이 원하는 레벨의 결과를 출력할 수 있도록 입력 텍스트를 변형하는 방법
- 장점 : 추가 학습 없이 사전학습된 모델의 예측 성능을 끌어올리 수 있음
- 단점 : 프롬프트를 사람이 직접 설계해야 한다는 부담이 있으며 성능 향상이 제한적

프롬프트 튜닝
- 학습 가능한 프롬프트로서, 가상 토큰(virtual token)을 입력에 추가
- 역전파를 통해 오직 가상 토큰에 대한 입베딩만 학습하고 나머지 모델은 고정
- 장점
    - 사람의 디자인 없이 스스로 프롬프트를 학습할 수 있음
    - 사전학습된 모델을 고정할 수 있음 (지식 손실x)
    - 적은 비용으로 새로운 데이터셋의 모델을 학습할 수 있음
- 학습된 프롬프트는 해석 X (그저 숫자 열 일뿐)

Adaptor 모듈 추가 학습
- 학습 가능한 작은 모듈을 레이어마다 삽입하여 일부 파라미터만 학습하는 기법

## 2-1. 합성데이터 활용법1
Knowledge Distillation (Teacher-Student 학습)
- 사전학습된 고성능 모델의 지식을 작은 모델에 압축해서 빠르고 효율적으로 만들 수 없을까?
- 지금까지 배운 미세조정과 같은 전이학습은 사전학습된 모델과 새로 학습할 모델의 구조가 동일한 경우를 가정하고 있었음

지식증류 : 높은 성능의 무거운 모델(선생님)을 모방하도록 가벼운 모델(학생)을 학습하는 방법
- 또는 크기가 작은 모델(student)만으로 충분히 학습하기 어려운 데이터 특징을 학습하기 위해 비교적 무겁고 성능이 높은 모델(teacher)의 도움을 받는 기법으로 볼 수 있음
- 선생님 모델이 예측한 soft-label 값과 학생 모델의 예측 값이 가까워지도록 학습 유도


## 합성데이터 활용법 2
InstructPix2Pix
- 기존 범용 데이터셋 : {이미지, 이미지 설명(캡션)}
- 지시사항(Instruction) 기반 이미지 편집을 지도학습 문제로 전환(입력 데이터-정답 쌍 필요)
- 가장 먼저, {이미지 편집에 대한 지시사항, 편집 전 이미지, 편집 후 이미지} 형식의 학습 데이터셋 생성

* Input에 있는 이미지 캡션을 가져온다.
* 명령을 추가하여 준다.
* 수정된 캡션을 사용하여 GPT를 파인튜닝 한다.
* 파인튜닝된 GPT는 창의적이면서도 그럴듯한 지시사항과 이미지 설명(캡션)을 생성한다.
* 기존 영상 생성 모델을 이용해 이미지 캡션 쌍으로부터 이미지 쌍을 생성한다.
* 생성된 이미지-명령 쌍 데이터셋을 기반으로, 최종 이미지 편집 생성 모델을 학습한다.

- 라벨 품질의 불일치

    - 같은 객체라도 프롬프트 방식 모델 버전 컨텍스트에 따라 라벨 표현이 달라질 수 있음

- 할루시네이션
    - 합성 데이터 생성 모델이 실제 존재하지 않는 객체, 특징, 관계를 마음대로 만들어내는 현상.
    - 실제 세계와 다른 패턴을 학습해 오류와 편향을 강화함.
    -> 개선 방안, 정교한 프롬프트, 후처리, 사실성 검증 모델, 실데이터 혼합
